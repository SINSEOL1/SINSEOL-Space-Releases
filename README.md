# 비움 · Bium

파일과 폴더 용량을 살펴보고, 직접 고른 항목만 정리하는 Windows 10/11 x64 프로그램입니다. SINSEOL Space의 새 이름이며 기존 설정·검사 기록·자동 업데이트는 유지합니다.

[최신 Windows 설치 파일과 변경사항](https://github.com/SINSEOL1/SINSEOL-Space-Releases/releases/latest)

## 주요 기능

- 파일별 추천 이유, 중복 기준 파일과 폴더별 용량 탐색
- 현재 목록 전체 선택·다중 선택·목표 용량 선택
- 확인 후 휴지통 이동, 정리 결과 확인과 드라이브별 휴지통 비우기
- 검사 기준·제외 폴더·검사 한도 설정과 검사 간 용량 변화
- 설치 프로그램 목록·검색·등록 용량 정렬 및 Windows 정식 제거 화면 연결
- Microsoft 기본 WinGet 공급원의 지원 프로그램 버전 조회와 선택 업데이트

큰 파일이나 오래된 파일이라고 삭제해도 된다고 판단하지 않습니다. Windows 보호 영역·링크·클라우드 자리표시자 등은 제외하며 검사 합계는 드라이브 전체 사용량과 다를 수 있습니다. 등록 프로그램 용량은 추정치이고 일부 Store·휴대용 앱·런처 게임은 표시되지 않을 수 있습니다.

휴지통 이동만으로 실제 여유 공간이 늘지는 않습니다. 휴지통 비우기는 선택한 드라이브에서 다른 앱이 버린 파일까지 영구 삭제하므로 별도 확인이 필요합니다.

파일 검사와 기록은 PC에서 처리합니다. 비움 자체 업데이트는 GitHub에, 사용자가 켠 프로그램 버전 조회와 설치는 Microsoft WinGet 공급원 및 각 배포처에 접속합니다. 미지원 프로그램을 최신 버전으로 표시하지 않으며 추가 설치 약관·권한·재부팅 안내는 직접 확인해야 합니다.

설치 파일명과 저장 경로에는 이전 버전 업데이트 호환을 위해 SINSEOL-Space/Space를 유지합니다. Windows 시작 메뉴와 설치된 앱에는 **비움**으로 표시합니다. 제거 후에도 설정과 기록은 보존합니다.

설정과 검사 기록: `%LOCALAPPDATA%\SINSEOL\Space`

자동 검증은 임시 파일·가짜 WinGet·Linux Qt offscreen·PowerShell 격리 설치 환경에서 수행했습니다. 실제 Windows 휴지통·WinGet 설치·UAC 동작은 개발 환경에서 검증하지 못했습니다.
