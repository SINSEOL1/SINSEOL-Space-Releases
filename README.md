# SINSEOL Space

드라이브 공간이 부족할 때, 정리할 후보를 이유와 함께 확인하세요.

시작 메뉴에서 SINSEOL Space를 실행한 뒤 드라이브나 폴더를 선택하고 검사를 시작합니다.
검토 목록에서 항목을 선택하면 추천 이유·확인사항·경로를 볼 수 있습니다.
파일 위치 열기로 원본 위치를 확인하세요. 프로그램은 파일을 삭제하거나 이동하지 않습니다.

## 알아두세요

- 파일이 크거나 오래됐다는 이유만으로 불필요한 파일이라고 판단하지 않습니다.
- 전체 내용이 같은 중복 파일은 기준 파일 하나를 남기는 방식으로 표시합니다.
- Windows 보호 영역, 링크, 클라우드 파일 등은 제외하며 검사 합계는 전체 사용량과 다를 수 있습니다.
- 확보 예상은 실제 삭제 결과가 아니며 파일 사용 여부는 직접 확인해야 합니다.
- 검사 경로와 집계 기록은 PC 밖으로 보내지 않습니다. 업데이트 확인 시 GitHub에 접속합니다.
- 업데이트는 다운로드와 검증을 마친 뒤, 다시 시작하고 설치를 눌러 적용합니다.
- 초기 개발 배포본은 첫 공개 릴리스 발행 전까지 업데이트 채널이 준비 중일 수 있습니다.

설정과 검사 기록: `%LOCALAPPDATA%\SINSEOL\Space`
프로그램 제거: Windows 설치된 앱 → SINSEOL Space. 설정과 검사 기록은 보존됩니다.
